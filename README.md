## 项目简介

这是一个非官方的线上虚拟展厅，内容整理自微信公众号「獭的游乐场」的《故宫“典则”唐宋书画大展全整理》系列文章。

它不是一篇可以一直往下滑的图文长页，而是一条有空间、有动线、有展签、有细节的观展路线：

- 从东晋“二王”的行草新范，走到南宋四家的边角新境；
- 在横向展墙前拖动、滚动，像在展厅里一样移动；
- 点击任意画作，放大看笔触、题跋、印章与装裱；
- 通过特征标签和关系动力图，看到作品之间的风格、题材与师承联系。

项目只包含前端程序，不依赖后端、数据库或构建工具。展品图片直接引用公众号图床，因此仓库体积很小，但浏览时需要联网。

## 功能亮点

### 观展

- **8 个按时代划分的展厅**：东晋南北朝、隋唐绘画、隋唐书法、五代、两宋书法、北宋绘画、南宋绘画、南宋四家。
- **横向 3D 展墙**：鼠标拖动、滚轮、触屏滑动或方向键移动；画作会随视角产生轻微景深变化。
- **苹果 Dock 式动效**：指针靠近画作时放大、上浮；点击时回弹放大并扫过一道边框高光。
- **展厅门槛**：进入每个展厅前先读本厅导语与关键词知识卡，建立时代背景。

### 展品细节

- **高清看图**：滚轮缩放、拖动查看、双击放大；支持多图册页的缩略图切换。
- **长卷与册页方向**：长卷、碑铭拓本册、经册默认横向展开；手机全屏中长卷可纵向阅读，从卷首开始。
- **手机全屏**：全屏铺满视口，支持双指捏合缩放、拖动浏览和右上角退出。
- **下载大图**：按原图分辨率导出，右下角自动加“獭的游乐场”水印，方向与当前查看一致。

### 知识与关系

- **特征标签**：每件展品 2–5 个标签，覆盖风格、题材、书体、门类、材质。
- **标签百科**：点击标签查看介绍，并列出相关展品，可直接跳转。
- **关系动力图**：以当前展品为中心，按同作者、同风格、同题材、同厅连线。
- **延伸阅读**：部分展品附作者撰写的专门赏析文章链接。

### 浏览体验

- **展品目录**：按展厅筛选、按展品名/作者/朝代搜索，一键跳到任意展品。
- **观展进度**：记录已看展品，底部展线显示各厅访问状态。
- **手机底栏**：显示展厅名称而不是序号，可横向滑动，当前展厅自动高亮。
- **背景音乐**：默认开启，程序化古琴曲《高山流水》主题，可随时关闭。
- **响应式与键盘**：电脑、平板、手机均可使用；详情页支持 `←` `→` 切换展品、`Esc` 返回，展厅支持 `Home` / `End` 到展墙两端。

## 快速开始

### 方式一：直接打开

克隆仓库后，双击 `index.html` 即可。

```bash
git clone https://github.com/againster1992-debug/dianze-virtual-museum.git
cd dianze-virtual-museum
```

### 方式二：本地服务器（推荐）

```bash
python -m http.server 8000
```

然后打开：

```text
http://localhost:8000
```

### 方式三：GitHub Pages

1. 打开仓库 `Settings` → `Pages`
2. `Source` 选择 `Deploy from a branch`
3. `Branch` 选择 `main`，目录选择 `/ (root)`
4. 保存后访问：

```text
https://againster1992-debug.github.io/dianze-virtual-museum/
```

## 怎么逛

1. **进入展厅**：点击首页“进入展厅”，再点击门槛页的“进入展厅”。
2. **移动**：按住鼠标左右拖动、滚动滚轮，或使用左右方向键。
3. **看画**：点击任意画作进入详情。左侧看图，右侧读展签、标签、介绍与关系图。
4. **换图**：多图册页在左下（桌面）或图片下方（手机）切换缩略图。
5. **全屏**：手机详情页点“全屏”，可双指缩放、拖动；点右上角 `×` 退出。
6. **找展品**：右上角“展品目录”可按展厅筛选或搜索作者、作品名。
7. **看百科**：点击标签，查看词条与相关展品；点击相关展品可跳转。
8. **保存**：详情页“保存”导出带水印原图；界面内查看时不显示水印。
9. **音乐**：右上角 `♪` 开关古琴背景音乐，默认开启。

## 数据与自定义

所有展品数据都在 `assets/data.js` 的 `window.MUSEUM_DATA` 中：

```js
window.MUSEUM_DATA = {
  meta: { total: 100, roomCount: 8 },
  rooms: [{
    chapter: '第一展厅',
    title: '东晋南北朝',
    subtitle: '典则初立',
    intro: ['展厅导语'],
    knowledge: [{ term: '高古游丝描', text: '知识卡' }],
    exhibits: [{
      id: 'u1e01',
      name: '行书摹东晋王羲之兰亭序帖卷',
      dynasty: '唐',
      artist: '褚遂良',
      material: '纸本',
      intro: ['展品说明'],
      detailLink: 'https://mp.weixin.qq.com/...',
      isScroll: true,
      scrollPos: 30,
      tags: [{ name: '行书', kind: 'script' }],
      hero: { src: 'https://mmbiz.qpic.cn/...', w: 1000, h: 600 },
      images: [{ src: '...', full: '...', w: 1000, h: 600 }]
    }]
  }]
};
```

替换成自己的展览时，注意：

- 图片使用公众号 `mmbiz.qpic.cn` 地址；页面和图片都设置 `no-referrer`。不要把图片下载进仓库。
- 竖长但应横置的碑铭拓本册、经册，把展品 `id` 加入 `assets/app.js` 的 `HORIZONTAL_ALBUMS`。
- 更换品牌、首页三张缩略图、标签百科与下载水印时，搜索 `index.html` 和 `app.js` 中的“典则”“獭的游乐场”等文案。
- 长卷判断规则：名称含“卷”且不含“册/页/轴”为长卷；题跋页不参与旋转。
- 修改后检查每个展品至少有一个 `hero`、一张 `images`、2–5 个标签和非空简介。

## 技术说明

- 原生 HTML / CSS / JavaScript，无框架、无构建。
- CSS 3D 展墙与响应式布局。
- Web Audio API 程序化生成古琴音色，不加载外部音频。
- Canvas 导出带水印图片，支持长卷旋转与超大图。
- 图片按需加载 + 微信图床直链。
- 面向现代浏览器（Chrome、Edge、Safari、Firefox）；已在 Chrome、Edge 及 390px / 360px 手机视口验证。

## 常见问题

**图片不显示？**  
确认网络能访问 `mmbiz.qpic.cn`，并保留页面里的 `no-referrer` 设置；部分网络环境会限制微信图床。

**音乐没有声音？**  
浏览器要求用户手势后才能播放。首次点击页面任意位置会自动启动；也可点右上角 `♪` 检查开关。

**长卷方向不对？**  
普通长卷应横向；手机全屏中可纵向。碑铭拓本册、经册应始终横向，检查 `HORIZONTAL_ALBUMS` 是否包含对应 `id`。

**如何换展品？**  
编辑 `assets/data.js`，保留字段结构；图片地址必须是可访问的微信图床链接。
